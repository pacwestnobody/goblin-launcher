Enroll a new key
  1. Plug the stick into this machine. It must not be mounted.
  2. Pick it below and type the confirm phrase shown.
  3. The stick is wiped and gets its own key. Your never-wipe list is always skipped.
Add a phone
  1. Turn on USB debugging (once per phone). Settings → About phone → tap Build number seven times until it says you're a developer. Then Settings → System → Developer options → turn on USB debugging.
  2. Plug it in and allow this computer. Use a data cable. The phone asks Allow USB debugging?: tick Always allow from this computer and tap Allow.
    Looking for a phone…
  3. Pair and install. Pick the USB key this phone belongs to, give it a name, and choose the phone's own PIN (4 to 12 digits, not your vault PIN). One button pairs it in the vault and installs the app with the pairing inside.
  4. On the phone: the app opens by itself. Type the same phone PIN once, then Turn the wheel to test it. For the lab menu and room, install Termux from F-Droid, then in Termux's app settings allow Display over other apps. You can turn USB debugging off again afterwards.
One phone per USB key: unpair the old one first to replace it. Revoking the key unpairs its phone too.
